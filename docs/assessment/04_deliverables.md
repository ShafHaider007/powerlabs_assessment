# 4. Deliverables

> Source: `docs/Technical Assessment.pdf`, Section 4 (wording copied from the PDF)

## From the PDF
> Submit the following:
> 1. **Video demonstration:** A maximum of 5 minutes, demonstrating your solution and its results.
> 2. **Python Source Code:** Host your solution in a **public GitHub repository**. Include a
>    well-structured README with setup instructions, dependencies, and clear steps to run the solution.
> 3. **Visual results:** Show the reconstructed roof, identified obstructions, and final panel placement.
> 4. **Brief technical explanation:** Describe your approach, key algorithms, assumptions,
>    limitations, and any incomplete tasks.

## Checklist
- [ ] **Video:** 5 minutes or less; demonstrates the solution and its results; spoken in clear English.
- [ ] **Public GitHub repo** with Python source.
  - [ ] README: setup instructions
  - [ ] README: dependencies (e.g. `requirements.txt` / `pyproject.toml`)
  - [ ] README: clear steps to run
- [ ] **Visual results**
  - [ ] Reconstructed roof (3D)
  - [ ] Identified obstructions
  - [ ] Final panel placement
- [ ] **Technical explanation**
  - [ ] Approach
  - [ ] Key algorithms
  - [ ] Assumptions
  - [ ] Limitations
  - [ ] Incomplete tasks (be honest)
